# md2png-service

[English](README.md) | [简体中文](README.zh-CN.md)

Render Markdown as a PNG through an HTTP API or MCP tools. Supports GFM tables, task lists, seven note-card themes, and custom footer text. Images are 800 pixels wide, with a height that follows the content up to 50,000 pixels.

A Bun/Hono gateway handles authentication and temporary image storage. A private Node/Playwright worker renders the images. The note-card renderer adapts [zhaoolee/notes](https://github.com/zhaoolee/notes).

## Start with Docker

Install Docker with the Compose plugin and start the Docker engine. The host does not need Node.js, Bun, or a browser. The first build downloads the Playwright image and npm dependencies.

1. Clone the repository and create the local configuration.

	```sh
	git clone https://github.com/hyperMoss/md2png-service.git
	cd md2png-service
	cp .env.example .env
	```

2. Edit `.env`. Replace `API_KEY` with a long random secret, for example one generated by `openssl rand -hex 32`. Keep `PUBLIC_BASE_URL=http://localhost:3000` for local use.

3. Build and start both services in the background.

	```sh
	docker compose up -d --build --wait --wait-timeout 180
	```

4. Check the gateway.

	```sh
	docker compose ps
	curl -fsS http://localhost:3000/health
	```

	The endpoint returns `{"status":"ok"}`. It checks the gateway only. Generate an image below to verify the worker too.

The API is available at `http://localhost:3000`. There is no web editor at `/`. Only the gateway publishes a host port, bound to `127.0.0.1:3000`.

Both services use `restart: unless-stopped`. Docker restarts them after a crash or a Docker engine restart unless you stopped them manually.

## Generate and download an image

These commands require `curl` and `jq`. Load your local `.env`, then send Markdown to the API.

```sh
set -a
. ./.env
set +a

curl -fsS "$PUBLIC_BASE_URL/v1/render" \
	-H "Authorization: Bearer $API_KEY" \
	-H 'Content-Type: application/json' \
	-d '{"markdown":"# Hello\n\n| One | Two |\n| --- | --- |\n| 1 | 2 |","theme":"bear","footer":{"brand":"My notes","via":"md2png"}}' \
	-o /tmp/md2png-result.json

jq . /tmp/md2png-result.json
curl -fsS "$(jq -er '.image_url' /tmp/md2png-result.json)" \
	-H "Authorization: Bearer $API_KEY" \
	-o /tmp/md2png-example.png
```

The response contains `image_url`, `width`, `height`, and `size_bytes`. Open `/tmp/md2png-example.png` to inspect the result. Downloads require the same bearer key by default. To allow browser previews and downloads without a key, set `PUBLIC_IMAGES=true` in `.env` and apply it with `docker compose up -d --build --wait`. This makes all unexpired image links readable without authentication, including existing images. Rendering and MCP still require the key. Set `PUBLIC_IMAGES=false` to require authenticated image access again.

To send a Markdown file, use the helper. It also requires Node.js on the host.

```sh
BASE_URL="$PUBLIC_BASE_URL" THEME=bear sh examples/render.sh examples/demo.md \
	> /tmp/md2png-result.json
curl -fsS "$(jq -er '.image_url' /tmp/md2png-result.json)" \
	-H "Authorization: Bearer $API_KEY" \
	-o /tmp/md2png-file.png
```

Replace `examples/demo.md` with your own file path. Set `THEME` to any supported theme.

See the [API and configuration reference](docs/reference.md) for themes, limits, error codes, MCP calls, and image handling.

With Node.js 24 or newer on the host, run `npm run smoke` to check the running API, authentication, PNG download, and MCP tools. It reads `.env` and saves a sample to `/tmp/md2png-smoke.png`. It does not require `npm ci`.

## Manage the deployment

View logs or stop and restart the services.

```sh
docker compose logs -f --tail=100
docker compose stop
docker compose start
```

After changing source files or `.env`, rebuild and apply the configuration.

```sh
docker compose up -d --build --wait --wait-timeout 180
```

`docker compose down` removes containers and networks but retains the named `images` volume. Images still expire after their TTL, which defaults to 24 hours. `docker compose down -v` also deletes the volume and its images.

If startup or rendering fails, inspect `docker compose logs --tail=100 gateway worker`. A `502` render response means rendering failed. A successful `/health` response does not prove Chromium can render. If port 3000 is occupied, change the host port in `docker-compose.yml` and set `PUBLIC_BASE_URL` to the matching URL.

For remote access, put an HTTPS reverse proxy or a tunnel in front of the gateway. Set `PUBLIC_BASE_URL` to the client-reachable URL and forward the `Authorization` header. Keep the worker private. See [deployment boundaries](docs/reference.md#deployment-boundaries).

## Develop without Docker

Install Node.js 24 and Bun, then install dependencies and Playwright Chromium. On Linux, `--with-deps` can require administrator access to install system packages.

```sh
npm ci
npx playwright install --with-deps chromium
```

Start the worker in one terminal.

```sh
npm run worker
```

In another terminal, load `.env` and start the gateway.

```sh
set -a
. ./.env
set +a
npm run gateway
```

The worker defaults to `127.0.0.1:3001`. Run the checks with Chromium installed.

```sh
npm test
npm run typecheck
```
